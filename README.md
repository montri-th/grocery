## ใช้งาน

```sh
npm start
```

เปิด <http://127.0.0.1:4173> เพื่อพัฒนาในเครื่อง; เปิดไฟล์ index.html โดยตรงจะนำไปยังเว็บสาธารณะด้านบน ข้อมูลหลักโหลดก่อน แผนที่ (MapLibre GL 5.6.2 จาก unpkg + OpenFreeMap vector tiles) โหลดภายหลังพร้อมสถานะและปุ่มลองใหม่ ขอบเขตอำเภอ/อปท. และรายละเอียดสาขาโหลดเมื่อเปิดจังหวัด/สาขา ไม่ต้อง build หรือติดตั้ง dependencies (Node ≥ 20 สำหรับ tests/scripts, Python 3 สำหรับ server) กราฟวาดด้วย HTML ภายในโปรเจกต์

```sh
npm test
```

ชุดทดสอบรันบนข้อมูลจริงที่หน้าเว็บใช้: การกระทบยอดกับ production, ลำดับชั้นพื้นที่และ Aha ทุกระดับ (รวม union ของสาขาที่อยู่สองพื้นที่ อปท. ที่คร่อมเขตอำเภอ และกรณีประชากรไม่ครบ), สเกล `count` / `density.capita` ตรง LDS ทุกค่าและสี 41 ขั้นแบบ `rank-41`, กราฟ, โปรไฟล์ อปท./สถานที่/สาขา, breadcrumb, ชั้นจุดและพื้นที่บนแผนที่, หมุด, โลโก้ (sha256), basemap, มวลอาคาร และการจับคู่สถานที่/อาคาร ส่วนความอ่านง่ายและพฤติกรรมในเบราว์เซอร์ตรวจแยกต่างหาก (`handoff/VERIFICATION.md`) สคริปต์ `npm run handoff:manifest`, `npm run handoff:bundle` และ `npm run verify:live` สร้าง manifest/bundle และเทียบ hash กับไฟล์บนเว็บจริง

## สิ่งที่สำรวจได้

- **ข้อค้นพบก่อน ตัวกรองทีหลัง:** แผงเปิดด้วย “X% ของสาขาอยู่ใน k พื้นที่นี้ ซึ่งมีคน[แค่] Y%” พร้อมแท่งเทียบสาขา–คน และแผนที่โฟกัส k พื้นที่นั้นแล้ว ปุ่ม “ดูทุก…” ยกเลิกโฟกัส (`?areas=all`) ปุ่ม “เปรียบเทียบ…” เปิดกราฟ ชื่อพื้นที่กดเพื่อเจาะลง
- **คำถามเดียวทุกระดับ:** ประเทศ → จังหวัด → อำเภอ/เขต → อปท./ย่าน (กรุงเทพฯ ใช้ Locale ของ CityMETER) ระดับ อปท./ย่านบอกว่าสาขาต่อคนมากกว่าหรือน้อยกว่าค่าเฉลี่ยของอำเภอ และอันดับในอำเภอ
- **จำนวน ↔ ต่อคน:** สวิตช์ในคำอธิบายแผนที่และในอันดับ: จำนวนสาขา (LDS `count`) หรือสาขาต่อ 1 หมื่นคน (LDS `density.capita`) ครบ 41 ขั้นของ LDS ตามลำดับค่า (`rank-41`) HEX เดียวกันทั้งสองธีม พื้นที่ไม่มีประชากรแสดง “ไม่มีข้อมูล” ไม่ใช่ศูนย์
- **focus + quiet:** เฉพาะพื้นที่ที่โฟกัสมีสี ป้าย และจุดสีประเภท ส่วนอื่นเหลือเส้นขอบ ป้ายจาง และจุดเทาเล็ก ๆ ที่ยังคง “1 จุด = 1 สาขา”
- **ทุกสาขาบนแผนที่:** 27,612 จุด WebGL (source เดิม 27,607 + สาขาทางการเพิ่ม 5) ไม่รวมจุด ไม่ย้ายพิกัด ซูมถึง 14 จุดในโฟกัสกลายเป็นหมุดพร้อมโลโก้แบรนด์หรือรูปแบบ (≤ 450 หมุด, ≤ 250 โลโก้) ใช้คีย์บอร์ดได้
- **รายละเอียดสาขา:** ประเภท รูปแบบ สถานะ ที่อยู่ ตำบล พื้นที่ สถานที่ตามชื่อสาขา (พร้อมโลโก้และบทบาท) พิกัดและระดับความแม่น แหล่งข้อมูลและวันที่ uuid ลิงก์ค้นหาสาขาของแบรนด์ / tile ต้นทาง / CityMETER และสาขาของแบรนด์เดียวกันในพื้นที่
- **breadcrumb:** ประเทศไทย › จังหวัด › อำเภอ/เขต › อปท./ย่าน › สถานที่ ด้วยรหัสเดียวกับ production (`?province=CBI&district=2004&unit=<DOLA>`)
- **กราฟสามมุมมอง:** สาขาเทียบคน (แท่งคู่ หรือต่อคน) · ประเภทร้าน (ตารางตัวเลข ช่องเท่ากัน) · แบรนด์ — ทุกแท่งและช่องเป็นปุ่มจริงและใช้สี 41 ขั้นของ LDS แบบเดียวกับแผนที่
- **ตัวกรอง:** ค้นหา (หลายคำ: แบรนด์ ชื่อสาขา พื้นที่ สถานที่) แบรนด์ รูปแบบ ประเภทร้าน และเลือกจังหวัด › อำเภอ › อปท. จาก disclosure พร้อมชิป; URL เก็บทุกสถานะ
- **3D:** มวลอาคารทั้งเมืองจาก OpenStreetMap เป็นบริบทเงียบ เมื่อเลือกสาขาหรือสถานที่ แสดงอาคารที่มีข้อมูล พร้อมแยกว่าได้จากพิกัดสาขาหรือชื่อสถานที่ คงพิกัดต้นทางทุกจุด กล้องแบบโมเดลเมือง (FOV 14°); ระดับสถานที่ใช้มุมสถาปนิก (two-point: pitch 75 / FOV 24) พร้อม venue x-ray ให้อาคารของสถานที่มองเห็นและกดได้เสมอ (รุ่น 0.2); ปุ่ม 3D สลับเป็นแผนผัง

โครงสร้างหน้าจอยึด CityMETER production และ Luxury Brands: header 48 px แผนที่เต็ม viewport ที่เหลือ แผงขวา `min(max(300px, 28%), 440px)` และถาดกราฟซ้อนด้านล่างที่ย่อได้ (52 px) จอมือถือแนวตั้งใช้ bottom sheet ไม่เกิน 64dvh พร้อมการ์ด Aha ย่อบนแผนที่เมื่อแผงปิด

basemap ทั้งสองธีมสร้างเองใน `js/map-style.js` บน [OpenFreeMap](https://openfreemap.org/) vector tiles (OpenMapTiles schema, ข้อมูล OpenStreetMap) ด้วยสี `--basemap-*` ใน `assets/theme.css` โดยคง attribution ของ OpenFreeMap, OpenMapTiles และ OpenStreetMap

## Data and method

อ่าน [Product statement](PRODUCT_STATEMENT.md), [DATA_METHOD.md](DATA_METHOD.md) และ [หน่วยพื้นที่](docs/AREA_METHOD.md) ก่อนตีความผล จำนวนสาขาในข้อมูลไม่ใช่ส่วนแบ่งตลาด ยอดขาย กำลังซื้อ ความอิ่มตัว หรือความครบถ้วนของร้านขายของชำในไทย และ “ต่อ 1 หมื่นคน” เป็นอัตราส่วนกับประชากรตามทะเบียน ไม่ใช่คำกล่าวอ้างเรื่องพฤติกรรม

ตรวจพิกัดเดิมครบ 27,607 แถวกับ snapshot อาคารแบบรวมแหล่ง: CityMETER V4 ที่พบรูปทรงครอบ → รูปทรงอ้างอิงที่ตรวจแล้ว → Microsoft Global ML Building Footprints release 2026-08-13 เติมช่องว่าง ผลเดิม 806 จุดภายใน / 9,328 จุดชิดขอบ / 17,473 จุดไม่พบรูปทรงครอบคงเดิมทุกแถว รอบ Foodplace ตรวจ 5 พิกัดทางการเพิ่มกับ Microsoft สอง partition ที่เก็บไว้แล้ว ได้ภายใน 2 / ชิดขอบ 1 / ไม่พบ 2 รวมปัจจุบัน **808 จุดภายใน · 9,329 จุดชิดขอบ · 17,475 จุดไม่พบรูปทรงครอบ** ([ผลจับคู่](data/spatial-joins.json), [ที่มาและสิทธิ์](data/building-sources.json)) ไม่ยกระดับผลชิดขอบ/กำกวมด้วยผลภายในของแหล่งถัดไป เกณฑ์ขอบ 10 ม. เป็นเกณฑ์ทบทวน ไม่ใช่ความแม่นพิกัด และการประมวลผลครบทุกแถวไม่ได้หมายถึงชุดข้อมูลมีอาคารจริงครบทุกหลัง

อาคารของสถานที่ตามชื่อสาขาชุดปรับปรุง 25 ต.ค. มี **31 venue / 78 features / 46 สาขาที่มีหลักฐานเชื่อม** โดยรักษาชุดเดิม 29 / 76 / 44 และเพิ่ม Forum · One Bangkok เฉพาะ `bigc-official-15068` กับอาคารจอดรถ · PARC Bangna เฉพาะ `bigc-official-15073` เป็นบริบทอาคารจากหลักฐานระบุตัวตน ไม่ขยายไปยังร้านอื่นในโครงการ ทั้งสองพิกัดทางการยังอยู่นอกรูปทรงและคง `no_building`; ไม่ย้ายจุดหรือเปลี่ยนยอดผลทดสอบพิกัดด้านบน ดู [หลักฐานติดตาม](data/retail-followup-evidence.json)

ความสูงที่เลือกของทั้งสองอาคารยังไม่ทราบ ค่า 3 ม. ใช้วาดภาพเท่านั้น PARC มีข้อมูลเจ้าของว่าร้านอยู่ชั้น Ground ของอาคารจอดรถ 3 ชั้น ซึ่งไม่แปลงเป็น 9 ม.; ค่าแบบจำลอง 16.75 ม. / 4 ชั้นเก็บแยกไว้โดยไม่ใช้เป็นความสูงที่ยืนยันแล้ว รูปทรงชื่อสถานที่ ผลพิกัด และสถานะการเปิดร้านยังเป็นหลักฐานคนละเรื่อง ชุดติดตามนี้เตรียมแล้ว; การเผยแพร่ต้องอ้างอิง release receipt และผลตรวจ live ที่ตรง commit ไม่ใช้ผลตรวจรุ่นก่อนรับรองรุ่นนี้
