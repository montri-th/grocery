# กราฟเปรียบเทียบพื้นที่

รุ่น 0.1 (22 ตุลาคม 2569) วาดกราฟด้วย HTML ใน `js/charts.js` โดยไม่มีไลบรารีภายนอก (แนวทางเดียวกับ Luxury Brands 0.2+) โมเดลตัวเลขอยู่ใน `js/chart-model.js` ทุก mark เป็น `<button>` จริง จึงใช้เมาส์ คีย์บอร์ด และ screen reader ได้เท่ากัน ไม่มี animation ไม่มีข้อมูลตัวอย่างปะปน

| มุมมอง / key | คำถามที่ตอบ | รูปแบบ | สี | การเลือก |
| --- | --- | --- | --- | --- |
| สาขาเทียบคน / `ranking` (จำนวนสาขา) | พื้นที่ใดมีส่วนแบ่งสาขามากกว่าส่วนแบ่งคน | แท่งคู่ต่อพื้นที่: ส่วนแบ่งสาขาของพื้นที่แม่ + ส่วนแบ่งประชากร ตัวเลขร้อยละทศนิยม 1 ตำแหน่ง อันดับ ชื่อ | แท่งสาขา = ระดับ `count` ของพื้นที่ (ชุดเดียวกับแผนที่) · แท่งคน = สีกลาง ไม่ใช่สีข้อมูล | กดแถวเพื่อเจาะลง |
| สาขาเทียบคน / `ranking` (ต่อ 1 หมื่นคน) | พื้นที่ใดมีสาขาต่อคนมากที่สุด | แท่งแนวนอน สาขาต่อ 1 หมื่นคน + จำนวนสาขากำกับ | ระดับ `density.capita` ของพื้นที่; ไม่มีประชากร = แท่งสีกลางเต็ม “—” | กดแถวเพื่อเจาะลง |
| ประเภทร้าน / `mix` | ประเภทร้านใดอยู่ในพื้นที่ใด | ตารางตัวเลข พื้นที่ ≤ 12 × ประเภทร้านที่มีในพื้นที่แม่ ตัวเลขทุกช่อง **ทุกช่องขนาดเท่ากัน** (`table-layout: fixed` + `<colgroup>`) | พื้นช่องตามระดับ `count` ของค่าในช่อง (legend แยกใต้ตาราง) 0 = เส้นขอบศูนย์ | กดช่องหรือชื่อพื้นที่ |
| แบรนด์ / `brands` | เชนใดอยู่ในพื้นที่ใด | ตารางตัวเลข พื้นที่ ≤ 12 × แบรนด์นำ ≤ 8 ของพื้นที่แม่ ช่องเท่ากัน | เหมือน `mix` | กดช่องหรือชื่อพื้นที่ |

เหตุผลของแท่งคู่: Aha แรกของรุ่นนี้คือ “สาขากระจุกเทียบคน” กราฟอันดับจึงแสดงคำถามเดียวกันรายพื้นที่ — ความต่างระหว่างแท่งสาขากับแท่งคนคือสิ่งที่ผู้ใช้ต้องเห็น แท่งคนเป็นสีกลางเพื่อไม่ให้อ่านเป็นตัวชี้วัดข้อมูลอีกชุด (INV19) และมีป้าย “สาขา / ประชากร” ในคำอธิบาย ถ้าพื้นที่ย่อยใดไม่มีประชากร แท่งคนหายทั้งกราฟและ caption บอกว่าแสดงเฉพาะสาขา

เหตุผลของตารางตัวเลขแทน bubble matrix: ยกจาก Luxury Brands — ตัวเลขแน่นอนทุกช่อง non-color cue คือตัวเลขเอง ช่องเท่ากันทุกช่องเพราะขนาดไม่มีความหมาย (INV18)

## ความหมายของจำนวน

`buildRankingModel(model, rows, compareSel, metric)` และ `buildMatrixModel(model, rows, compareSel, columns)` รับแถวหลังตัวกรอง (`filtered`) และพื้นที่ที่เทียบ (`compareSel` = พื้นที่ปัจจุบัน; ระดับ อปท. ใช้อำเภอของมัน จึงเทียบกับพี่น้อง) แล้วใช้ `summarizeChildren` / `comparisonRows` / `areaRows` ของ `js/hierarchy.js` เป็นเจ้าของการนับ — กติกาเดียวกับ Aha และแผนที่ (matrix นับสมาชิกทั้งหมดของแต่ละพื้นที่ย่อย ผลรวมแต่ละแถวจึงเท่ากับจำนวนสาขาของพื้นที่นั้น)

- **สาขา:** จำนวน source rows ในพื้นที่ย่อย (อปท./ย่านนับสมาชิกของ production; สาขาในสองพื้นที่นับทั้งสอง)
- **ส่วนแบ่งสาขา:** สาขาของพื้นที่แม่ที่อยู่ในพื้นที่ย่อย (`inArea`) ÷ สาขาทั้งหมดของพื้นที่แม่ — กติกาเดียวกับ Aha ส่วนตัวเลขจำนวนสาขาที่แสดงคือยอดเต็มของพื้นที่ย่อย (อปท. ที่คร่อมเขตอำเภอจึงอาจมีจำนวนมากกว่าส่วนที่นับในส่วนแบ่ง เช่น ทน.แหลมฉบัง 152 สาขา แต่ 130 สาขาอยู่ในศรีราชา) (ผลรวมของส่วนแบ่งระดับ อปท./ย่านไม่จำเป็นต้องเท่ากับ 100% พอดี: 15 สาขาอยู่สองพื้นที่ และบางสาขาของอำเภอเป็นสมาชิกของ อปท. ในอำเภอข้างเคียงหรือไม่อยู่ใน Locale ใด — ดู [AREA_METHOD.md](AREA_METHOD.md))
- **ส่วนแบ่งประชากร:** ประชากรของพื้นที่ย่อย ÷ ผลรวมประชากรของพื้นที่ย่อยทั้งหมด แสดงเมื่อทุกพื้นที่ย่อยมีประชากร
- **ต่อ 1 หมื่นคน:** สาขา ÷ ประชากร × 10,000; ไม่มีประชากร = ไม่มีข้อมูล ไม่ใช่ศูนย์
- พื้นที่ที่เลือกบนแผนที่ถูกไฮไลต์ (`selectedIndex`) แต่ไม่ตัดพื้นที่อื่นออก caption ระบุจำนวนพื้นที่และขอบเขตที่เทียบ

ส่วนแบ่งและความหนาแน่นเป็นคำบรรยายภายในชุดข้อมูล 17 เชนนี้ ไม่ยืนยันยอดขาย อุปสงค์ ความอิ่มตัว หรือศักยภาพของพื้นที่

## สีและระดับ

สีมาจาก `js/scales.js#buildScale` ใช้ครบ 41 ขั้นของ LDS เสมอ (กติกาเจ้าของ 22 ต.ค. 2569): วิธี `rank-41` บนค่าที่ปัดตามที่แสดง (จำนวนเต็ม / ทศนิยม 1 ตำแหน่ง) ค่าน้อยสุด = ขั้น 0 มากสุด = ขั้น 40 ค่าเท่ากันได้ขั้นเดียวกัน ตัวเลขที่แสดงกับสีที่ระบายจึงตรงกันเสมอ กราฟอันดับใช้ค่าของพื้นที่ย่อย (ชุดเดียวกับแผนที่ สีจึงตรงกับแผนที่) ส่วนตารางใช้ค่าของช่อง จึงมี legend 41 ขั้นของตัวเอง (`js/ramp-legend.js`: แถบ 41 ช่องสีจริง ขีดใต้ขั้นที่มีค่า และค่าน้อยสุด · ค่ากลาง · มากสุด) สีตัวอักษรบนพื้นช่องเลือกจาก `inkFor`; ขั้นที่หมึกทั้งสองไม่ถึง 4.5:1 (`count` 27–29) วางตัวเลขบนแผ่นรองสีกลาง (ตรวจใน `tests/scales.test.js`) HEX เดียวกันทั้งสองธีม

## Integration contract

`renderInsightChart({elementId, view, theme, model, rows, compareSel, metric, selectedIndex, childNoun}, onSelect)` คืน disposer; ทุก mark ส่ง `{type: 'area', level, index}`; ไม่มีพื้นที่ย่อย = “ไม่มีพื้นที่ย่อยให้เปรียบเทียบ”; ไม่มีแถว = “ไม่พบสาขาตามตัวกรอง”; error = ข้อความชี้ไปตาราง แอปเป็นผู้รักษาตัวกรองและการเลือก

## การตรวจ

`tests/chart-model.test.js` ตรวจค่าจริง (ประเทศ: 77 จังหวัด 27,607 สาขา ส่วนแบ่งสาขาและคนรวมเป็น 100% กรุงเทพฯ อันดับหนึ่งตามจำนวน ภูเก็ตอันดับหนึ่งตามต่อคน), การไม่แสดงส่วนแบ่งคนเมื่อพื้นที่ย่อยขาดประชากร (เขตดุสิต), อปท. ที่คร่อมเขตอำเภอ (ทน.แหลมฉบัง: ยอดเต็ม 152 ทั้งในอันดับและ matrix ส่วนแบ่งนับ 130), matrix ประเภท/แบรนด์ที่ผลรวมแต่ละแถวเท่ากับสาขาของพื้นที่ และกรณีไม่พบแถว `tests/scales.test.js` ตรวจ LUT, การจัด 41 ขั้น (`rank-41`), legend 41 ช่อง และ contrast ผลหน้าจอจริง (ความอ่านง่าย คลิก คีย์บอร์ด ธีม) บันทึกใน `handoff/VERIFICATION.md` แยกจาก unit tests
