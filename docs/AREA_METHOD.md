# หน่วยพื้นที่ของ CityMETER Grocery

รุ่น 0.1 · 22 ตุลาคม 2569 · ตัดสินใจโดยเจ้าของผลิตภัณฑ์ (ตัวเลือก “A+อปท”)

## ตัดสินใจอะไร

Luxury Brands ใช้ “ย่าน” เชิงวิเคราะห์ 10 แห่งที่นิยามเอง เพราะแบรนด์หรูกระจุกในไม่กี่ย่านของกรุงเทพฯ แต่ร้านค้าปลีกอาหาร 27,607 สาขากระจายทั่วประเทศ คำถามของผู้ใช้จึงเป็นคำถามระดับพื้นที่ปกครองที่ทีมขยายสาขาและหน่วยงานใช้จริง เจ้าของเลือกใช้ **ลำดับชั้นเดียวกับ CityMETER production**:

| ระดับ | นอกกรุงเทพฯ | ในกรุงเทพฯ | จำนวน | key |
|---|---|---|---|---|
| 1 | จังหวัด | กรุงเทพมหานคร | 77 | ตัวย่อ production (`BKK`, `CBI` …) |
| 2 | อำเภอ | เขต | 928 | รหัส 4 หลัก (`1039`, `2004` …) |
| 3 | อปท. (ทน./ทม./ทต./อบต./เมืองพัทยา) | ย่าน (CityMETER Locale) | 7,774 + 847 = 8,621 | รหัส DOLA / uuid ของ Locale |

ทางเลือกที่ไม่ใช้: (1) Locale อย่างเดียว — มีเฉพาะกรุงเทพฯ ใช้กับทั้งประเทศไม่ได้ (2) ย่านเชิงวิเคราะห์แบบ Luxury — ต้องนิยามขอบเขตเองและตัวเลขจะไม่ตรงกับ production

## กติกา

1. **ไม่สร้างพื้นที่เอง** ทุกขอบเขต ชื่อ รหัส ประชากร และพื้นที่ ตร.กม. มาจาก production (`base/info`, `grocery/info`, `grocery/info/geom`)
2. **สมาชิกภาพเป็นของ production** อำเภอจากตำบลที่แถวนั้นถูกส่งมา; อปท./ย่านจาก overlay tile ของพื้นที่นั้น (ไม่ใช้ point-in-polygon ของเดโม) ผลคือยอด อปท./ย่านเท่ากับ API ครบทุกแห่ง
3. **ระดับบนของ อปท./ย่าน** อปท. ใช้รหัสอำเภอที่ฝังในรหัส DOLA; ย่านใช้เขตที่สาขาส่วนใหญ่ของย่านรายงาน (เฉพาะเขตในกรุงเทพฯ) หรือเขตที่ซ้อนทับมากที่สุดเมื่อไม่มีสาขา
4. **คำถามเดียวทุกระดับ** พื้นที่ปัจจุบันเทียบพื้นที่ย่อยของตัวเองเสมอ: ประเทศ → จังหวัด, จังหวัด → อำเภอ/เขต, อำเภอ → อปท./ย่าน; ระดับ อปท./ย่านเทียบกับค่าเฉลี่ยของอำเภอ
5. **ประชากรเทียบภายในระดับเดียวกัน** ผลรวมประชากร อปท. ไม่เท่าประชากรอำเภอทุกแห่ง ส่วนแบ่งคนจึงหารด้วยผลรวมของพื้นที่ย่อยที่เทียบ ไม่ใช่ประชากรของพื้นที่แม่
6. **ไม่มีข้อมูล ≠ ศูนย์** พื้นที่ที่ไม่มีประชากรไม่คิดต่อคน และ Aha ของพื้นที่แม่ไม่เทียบกับจำนวนคน

## กรณีขอบ

| กรณี | จำนวน | วิธีจัดการ |
|---|---|---|
| สาขาอยู่ในสอง อปท./ย่านที่ขอบเขตซ้อนกัน | 15 | นับทั้งสองพื้นที่ (เหมือน production); ส่วนแบ่ง Aha นับครั้งเดียว |
| สาขาในกรุงเทพฯ ไม่อยู่ใน Locale ใด | 19 | ระดับละเอียดสุดคือเขต; breadcrumb ข้ามระดับย่าน |
| ตำบลของสาขาอยู่คนละอำเภอกับ อปท. ที่เป็นสมาชิก (25 อปท./ย่านคร่อมเขตอำเภอ) | 69 | ยอดของพื้นที่เท่ากันทุกที่: อำเภอนับตามตำบล, อปท./ย่านนับสมาชิกทั้งหมดของ production แม้ในมุมมองของอำเภอ; ส่วนแบ่งของอำเภอ (Aha, แท่งสาขา) นับเฉพาะสาขาของอำเภอนั้น |
| อปท./ย่านไม่มีประชากร | 163 | ต่อคน = ไม่มีข้อมูล; ไม่เทียบคนใน Aha ของอำเภอนั้น |
| อปท./ย่านไม่มีสาขาในตัวกรอง | 2,929 (ไม่กรอง) | ศูนย์ที่วัดได้: สีต่ำสุด + เส้นขอบศูนย์ |
| ยอดรวมต่างจากจุดที่มี | 1 (เกาะพะงัน) | แสดงจุดที่มีจริง ระบุยอด CityMETER ท้ายแผง |

## บนแผนที่และใน URL

- ขอบเขตจังหวัดโหลดตอนเริ่ม ขอบเขตอำเภอและ อปท./ย่านโหลดเมื่อเปิดจังหวัด (`data/geo/p/<code>.json`) ขอบเขตถูกย่อเพื่อแสดงผล การนับไม่ใช้ขอบเขตที่ย่อ
- สีของแต่ละระดับหยุดที่ zoom 9 (จังหวัด) / 12 (อำเภอ) / 14.5 (อปท./ย่าน) แล้วเหลือเส้นขอบ เพื่อให้จุดสาขาเป็นพระเอก
- demo: `?province=BKK&district=1039&unit=<uuid>`; production: `/v3/citymeter/BKK/L/<uuid>?d=grocery` (อปท. ใช้ `/M/<DOLA>`; production ไม่มี path ระดับอำเภอ)

รายละเอียดการดึงและกระทบยอดอยู่ใน [DATA_METHOD.md](../DATA_METHOD.md) §2–§4, §11 และ `data/build-receipt.json`
